# DummyShop – React Shopping Website

## 1. Project Description

DummyShop is a responsive shopping website developed using React.js. It allows users to browse products, view product details, add products to a cart, manage a wishlist, and proceed to checkout.

The project demonstrates the use of React components, props, state, hooks, Context API, routing, and API integration.

## 2. Features

- Display product listings.
- View individual product details.
- Add and remove products from the shopping cart.
- Manage wishlist items.
- Navigate between pages using React Router.
- Checkout page for reviewing orders.
- Fetch product data from an API.
- Responsive user interface.

## 3. Technologies Used

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Build Tool:** Vite
- **Routing:** React Router
- **Data Fetching:** Fetch API
- **Development Tools:** Node.js, npm, Visual Studio Code
- **Version Control:** Git and GitHub
- **Deployment:** Netlify

## 5. Installation and Setup

### Prerequisites

Install Node.js and npm before running the project.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Divya-bandari/dummyshop-spa.git
```

### Step 2: Navigate to the Project Folder

```bash
cd dummyshop-spa
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the website in your browser.

## 6. Testing

The project can be tested manually by checking the following functionality:

- Verify that the home page loads correctly.
- Check that products are displayed.
- Open a product's details page.
- Add and remove products from the cart.
- Add and remove products from the wishlist.
- Navigate between pages.
- Check the checkout page.
- Verify the layout on different screen sizes.
- Check the browser console for errors.

### Production Build Test

Run the following command to check whether the project builds successfully:

```bash
npm run build
```

If the build completes successfully, Vite generates the production files in the `dist` folder.

To preview the production build locally, run:

```bash
npm run preview
```
